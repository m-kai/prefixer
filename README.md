# prefixer

サービス名やキーワードに、ランダムな「枕詞」風の接頭語を付けてキャッチコピーを生成する小さな Web ツールです。

## 使い方

1. `index.html` をブラウザで開く（ローカルでそのまま開けます）。
2. テキスト欄にサービス名などを入力（例：エステ、コーチング、カフェ）。
3. 「名前を考える」を押すか、Enter キーで実行。
4. 表示された一文が、今日のおすすめキャッチコピーです。

接頭語は `prefixer.js` の `PREFIX` 配列からランダムに選ばれます。

## ファイル

| ファイル | 内容 |
|----------|------|
| `index.html` | 画面 |
| `prefixer.js` | 接頭語の付与ロジック |

任意の静的ファイルサーバーで配信しても動作します（例：`python3 -m http.server` をリポジトリ直下で実行し、ブラウザで `http://localhost:8000` を開く）。
